ПРИМЕР ИЗ ПОСТАНОВКИ
// Пользователь A
let answer = 10;
return answer + 1;        // 11

// Пользователь B
let answer = 50;
return answer + answer;   // 100
После публикации B решение A пересчитывается: answer = 50 → A возвращает 51.
Одна общая переменная — и результат меняется у всех, кто её использует.
40 секунд. Ключевая идея: переменные общие для всех. Пример A/B показывает, почему решение A меняет результат после публикации B. Дальше — как это работает на платформе.
